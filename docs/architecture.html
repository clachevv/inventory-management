View re-renders
Computed properties update; template reflects new data

Quarter notation (e.g. Q1-2025) maps to months 2025-01, 2025-02, 2025-03 on the backend. Inventory endpoints do not support month filtering (no time dimension in inventory data).

API Endpoints

Method Path Query Params Returns
GET /api/inventory warehouse, category List of inventory items
GET /api/inventory/{item_id} — Single inventory item
GET /api/orders warehouse, category, status, month List of orders
GET /api/orders/{order_id} — Single order
GET /api/demand — All demand forecasts
GET /api/backlog — Backlog items enriched with has_purchase_order
GET /api/dashboard/summary warehouse, category, status, month KPIs: inventory value, low stock count, pending orders, backlog count, order value
GET /api/spending/summary — Procurement, operational, labor, overhead totals + % changes
GET /api/spending/monthly — 12-month spending breakdown by cost category
GET /api/spending/categories — Spending by product category (Raw Materials, Components, etc.)
GET /api/spending/transactions — Recent individual transactions
GET /api/reports/quarterly — Q1–Q4 fulfillment rate, avg order value, revenue
GET /api/reports/monthly-trends — Month-over-month order count, revenue, delivery count

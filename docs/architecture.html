Filter System

4 Global Filters — managed by useFilters composable

All views share filter state. api.js omits any filter set to 'all' from query params.

Time Period — YYYY-MM or Q1–Q4-YYYY Warehouse — location filter Category — case-insensitive match Order Status — pending / shipped / delivered / backordered
Note: Inventory endpoints do not support month filtering (no time dimension in inventory data). Quarter format maps to months: Q1 = Jan–Mar, Q2 = Apr–Jun, Q3 = Jul–Sep, Q4 = Oct–Dec.
